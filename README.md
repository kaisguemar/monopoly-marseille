# Monopoly Marseille

Version marseillaise du Monopoly, jouable dans le navigateur.

## Structure

- `src/` : code du jeu (HTML, CSS, JS)
- `data/` : contenu du plateau (cases, quartiers, cartes Chance / Caisse de communauté)
- `assets/` : images et visuels

## Lancer le jeu

Ouvrir `src/index.html` dans un navigateur.
